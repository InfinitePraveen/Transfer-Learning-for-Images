About This Project

Project Overview

This project demonstrates the power of transfer learning for image classification tasks. We fine-tune two state-of-the-art deep learning models (VGG16 and ResNet50) on the Oxford 102 Flower Dataset to create an accurate flower classification system.

What is Transfer Learning?

Transfer learning is a machine learning technique where a model developed for one task is reused as the starting point for a model on a second task. In our case, we use models pretrained on ImageNet (1.4 million images, 1000 classes) and adapt them for flower classification.

Models Used

VGG16

  • 16 layers deep
  • 138 million parameters
  • Simple architecture
  • High accuracy on ImageNet

ResNet50

  • 50 layers deep
  • 25 million parameters
  • Residual connections
  • State-of-the-art performance

Dataset

We use the Oxford 102 Flower Dataset, which contains:

  • 8,189 images of flowers
  • 102 different flower categories
  • Each class has 40-258 images
  • Images have large scale, pose, and light variations
