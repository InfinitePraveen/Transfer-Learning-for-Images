Getting Started

This application allows you to classify flower images using transfer learning with VGG16 and ResNet50 models fine-tuned on the Oxford 102 Flower Dataset.

Installation

Prerequisites

  • Python 3.7 or higher
  • pip package manager
  • Git (optional)

Steps

git clone https://github.com/your-username/transfer-learning-images.git
cd transfer-learning-images
pip install -r requirements.txt

Usage Guide

Running the Application

python app.py

Open your browser and navigate to http://localhost:5000

Making Predictions

  1. Click on "Predict" in the navigation menu
  2. Upload an image (JPG, JPEG, or PNG)
  3. Select a model (VGG16 or ResNet50)
  4. Click "Predict" to see results

API Reference

Endpoints

Endpoint Method Description
/ GET Home page
/predict GET, POST Upload and predict image
/gallery GET View example predictions
/documentation GET View documentation

Models

VGG16

16-layer deep convolutional neural network

  • Input size: 224x224x3
  • Parameters: 138 million
  • Pre-trained on: ImageNet

ResNet50

50-layer residual network

  • Input size: 224x224x3
  • Parameters: 25 million
  • Pre-trained on: ImageNet

Dataset

The models are trained on the Oxford 102 Flower Dataset, which includes 8,189 images spanning 102 flower categories.

Dataset Statistics

  • Training images: 1,020 (10 per class)
  • Validation images: 1,020 (10 per class)
  • Test images: 6,149 (remaining)

Troubleshooting

Common Issues

File upload fails: Check that the file is JPG/PNG and under 5MB
Slow predictions: First prediction may be slow as models load into memory
CUDA errors: The app will automatically fall back to CPU if GPU is unavailable
